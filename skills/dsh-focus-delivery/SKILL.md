# 按实际结果交付

1. 对照最新用户要求和清单，找出遗漏、阻塞和未验证项。清单“已完成”是工作记录，不是成果正确的证明。检查通过后又修改成果，应核对受影响部分。
2. 复用仍适用的结果检查与证据。材料、代码、输入条件有变化或出现具体疑点时，补最少必要的检查。不为收尾计算无比较依据的文件哈希、创建快照；文件存在不等于内容正确。
3. 根据实际任务说明成果：调研结论给出关键依据与未知项；文稿和文件提供可用内容或位置；操作任务说明实际对象与状态，草稿或已受理不能说成已发送、已完成。网站和应用按本次改动核对真实交互，构建成功不代表功能正确；合成数据、本地示例和真实服务分别说明。
4. 只有实际完成的项目才标记完成。存在必要未完成项时继续解决或说明阻塞；不通过缩减需求、空壳、假数据或删除失败检查制造完成。
5. 按用户需要的格式，用简短中文交代成果、必要依据和仍有影响的限制；先给结果，不重复整套工作过程。给出可用内容、文件或运行入口，保留必要技术标识和原文。没有明确要求时不另造验收报告；满足完成条件就结束。

提交、推送、发布、安装以及子代理使用均以用户授权为准。本技能不自动增加这些操作。
